# Contributing

Please read the README, architecture documentation and ADRs before proposing a
change. Keep changes focused and add tests and documentation where relevant.

Before opening a pull request, run `composer validate --no-check-publish`,
`composer lint`, and `composer test`. Never include credentials, real user
data, generated logs, or local configuration. Substantial changes should be
discussed with maintainers first.

This project follows PES-001, PES-002, PES-003, PES-004, PES-006, PES-007 and
PES-008 from the polbeo Engineering Standards; the canonical standards remain
outside this public repository.
